A modern, high-performance developer portfolio built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Features interactive 60fps physics simulations, custom vector tech stack badges, smooth scroll-driven parallax, and a responsive project carousel.

🌐 **Live Demo:** [https://portfolio-two-swart-31.vercel.app](https://portfolio-two-swart-31.vercel.app)

---

## ✨ Features

- 🎯 **Scroll-Driven Parallax Hero**: Clean responsive typography with scroll animations and smooth background halftone waves.
- 🎨 **Interactive Physics Tech Stack**: Custom 60fps rigid-body physics engine simulating floating circular tech badges with hover-to-freeze states.
- 🚀 **Featured Projects Carousel**: Interactive project showcase featuring side navigation arrows, slide transitions, live links, and GitHub repositories.
- 🛠️ **Comprehensive Tech Arsenal**: Filtered grid of 26 curated developer tools with vector icons.
- 📱 **100% Fully Responsive**: Optimized for mobile, tablet, laptop, and ultra-wide displays.
- ⚡ **Lightning-Fast Performance**: Built on Next.js 15 App Router with optimized image assets and zero layout shifts.

## 🚀 Getting Started

### Prerequisites
Make sure you have **Node.js 18.x** or higher installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sahilsinghpanwar/PORTFOLIO.git
   cd PORTFOLIO
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view your local portfolio instance.
